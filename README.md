## 1. Project Overview

This project investigates predictive modelling, statistical sensitivity, high-confidence prediction errors, and fairness trade-offs using the Adult Census Income dataset.

The analysis compares Linear Regression and Logistic Regression, examines subgroup differences, evaluates omitted-variable sensitivity, identifies confidently incorrect predictions, and studies how decision thresholds affect fairness metrics.

## 2. Objectives

- Prepare and preprocess the Adult Census Income dataset.
- Train and evaluate Linear Regression and Logistic Regression models.
- Compare model classifications using an agreement matrix.
- Perform subgroup and omitted-variable sensitivity analyses.
- Identify high-confidence incorrect predictions.
- Evaluate fairness metrics across multiple decision thresholds.
- Discuss limitations and responsible use of predictive models.

## 9. Reproducibility and Limitations

All numerical results in the submitted report should be generated by the notebook code. Saved notebook outputs alone are not sufficient evidence of reproducibility; the notebook must run successfully from a fresh kernel.

Model associations should not be interpreted as causal effects. Fairness ratios describe particular statistical criteria and do not establish fairness in every ethical or legal sense. The results are specific to the dataset, selected features, modelling choices, and evaluation procedure.
